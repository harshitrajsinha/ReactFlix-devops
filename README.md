## <a name="introduction">Introduction</a>

Built with React.js for the user interface, Appwrite for backend services, and styled with TailwindCSS, this Movie App lets users browse trending movies, search titles, and explore content using the TMDB API. It features a responsive layout and a sleek, modern design.

## <a name="tech-stack">Tech Stack</a>
<p>Appwrite, ReactJS, React Use (Hooks), Tailwind CSS, Vite</p>

## <a name="quick-start">Quick Start</a>

Follow these steps to set up the project locally on your machine.

**Prerequisites**

Make sure you have the following installed on your machine:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/en)
- [npm](https://www.npmjs.com/) (Node Package Manager)

**Cloning the Repository**

```bash
git clone https://github.com/adrianhajdin/react-movies.git
cd react-movies

```

**Installation**

Install the project dependencies using npm:

```bash
npm install
```

**Set Up Environment Variables**

Create a new file named `.env.local` in the root of your project and add the following content:

```env
VITE_TMDB_API_KEY=

VITE_APPWRITE_PROJECT_ID=
VITE_APPWRITE_DATABASE_ID=
VITE_APPWRITE_COLLECTION_ID=
```

Replace the placeholder values with your actual **[TheMovieDatabase API](https://developer.themoviedb.org/reference/intro/getting-started)** and **[Appwrite](https://apwr.dev/JSM050)** credentials.

**Running the Project**

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the project.

### 🐳 Learnings from Dockerizing this reactjs-based application

1. [I learnt how to create NGINX configuration file to serve static files](#learning-1)<br>
    <a name="learning-1"></a>The build generated by the npm package manager requires a server that could serve the files - HTML, CSS, JS and any public assets when requested on browser. One of the popular option to do the task is to use a NGINX server, for which we are required to carefully configure it by specifying the port on which the request will land, the index file to serve, and to include the types of files that are allowed to be serve.
